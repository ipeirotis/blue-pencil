# Evaluation rubric (draft v0.3)

**Code grader:** fails the revision if any of these differ from the original.

| Item | Includes |
|---|---|
| Numbers and statistics | values, signs, units, p-values |
| Citations | added, removed, changed, or reordered |
| Equations and math | any symbol |
| Table and section references | "Table 3" |
| Quotes | quoted text |
| Markup | LaTeX, Markdown, code |

**Meaning grader:** fails the revision on any major problem, and quotes the original and revised wording for each problem.

| Item | Counts as a problem when | Severity |
|---|---|---|
| Claim strength | certainty changes: "associated with" becomes "causes" | Major |
| Caveat or scope | a condition or exception is dropped or widened | Major |
| New content | a claim not in the original is added | Major |
| Lost content | a finding, step, or definition is removed | Major |
| Reassigned value | a number, citation, or quote now belongs to a different claim | Major |
| Qualifier word | one is dropped: "novel" | Minor |
| Voice | the author's style is replaced | Recorded only |

**Quality grader:** compares two versions, blinded and in both orders, on how well they read.

| Dimension | Better looks like |
|---|---|
| Clarity | the point is easy to find early |
| Concision | fewer words for the same content |
| Flow | ideas connect through content |
| Precision | exact words, correct grammar |
| Audience fit | register suits the stated audience |
